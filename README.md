# 濒危语言词典编辑与审校工具

`sologsb-1021` 是一个本地优先的濒危语言词典工作台，使用 Nuxt 3、Vue 3、Pinia 和 TDesign Vue Next 从零构建。

## 功能

- 维护词形、发音说明、方言变体、词性、例句、来源、同义词和编者备注。
- 词条支持草稿、待审、争议、已确认四种状态，可快速提交审校或确认。
- 审校意见可绑定到具体字段，编辑可以逐条回复、重新打开或标记为解决。
- 自动检测词形、同义词和释义高度相似的重复词条。
- 重复词条并排比较，可选择主条并逐字段选择“主条 / 另一条 / 拼接”；变体、例句、来源和意见全部保留。
- 删除词条前扫描其他词条的同义词、释义和例句引用，列出全部影响并阻止无意删除。
- 每次提交前保存完整版本快照，支持撤销重做、版本恢复和操作审计。
- 全文搜索、状态筛选、方言筛选，以及 J/K、搜索、查重、版本和通用撤销快捷键。
- 使用浏览器 localStorage 离线保存，刷新或断网后继续编辑。

## 离线副本交换与合并（田野—回到网络）

- 每个浏览器副本有唯一标识与可修改的副本名；每次字段修改都记录**版本向量、来源副本和修改时间**。
- 「同步副本」中心可导出给同事的**同步包**（词条 + 撤下墓碑），也可读入同事的同步包。
- 合并是基于版本向量的三方合并：
  - 因果上更新的一方自动胜出——**旧副本不会覆盖新的审校意见、已确认状态或任何字段**。
  - 同一词条两边都改过的**同一字段**逐字段保留两版，并排显示双方副本名与时间，编辑选择本副本 / 对方 / 拼接（同义词自动去重并集）。
  - 方言变体、例句、来源、审校意见与回复按 id 取并集，对方带来的内容标注来源副本。
- **撤下墓碑**：删除不是消失，撤下记录随同步包传播；旧副本带回的词条不会悄悄恢复。撤下与分叉后的继续编辑同时发生时进入「撤下复核」，必须显式选择保留或撤下，审校意见随墓碑保留。
- 合并在读取、裁决、写入各阶段失败（或断网）时**本地数据一律不动**：同步包、已做的裁决、失败阶段与失败位置随 `pendingMerge` 持久化，可一键「恢复并再次合并」或放弃。
- 合并成功的版本记录带 `mergeFrom`，明确写出**这次合并来自哪个副本**及对方同步包导出时间；审计与合并报告同样留痕，可在同步中心回看成功/失败记录。
- 同步中心内置「断网/中断演练」开关，可模拟各阶段失败来验证恢复流程。

## 技术栈

- Nuxt 3.21
- Vue 3.5
- Pinia 4
- TDesign Vue Next 1.20
- TypeScript 5.9

## 开发

```bash
npm install
npm run dev
```

开发服务器使用 Nuxt 默认端口，不在源码中硬编码宿主端口。

## 检查与测试

```bash
npm run typecheck   # vue-tsc 严格类型检查
npm run test:merge  # 合并引擎 40 项场景测试（版本向量 / 字段冲突 / 墓碑复活保护）
npm run test:store  # store 端到端：失败保留本地改动与失败位置、恢复再合并、版本来源留痕
```

## 生产构建

```bash
npm run build
```

项目使用 Nuxt 静态生成，产物位于 `.output/public/`。可在本地运行：

```bash
npm run preview
```

## Docker

```bash
docker build -t sologsb-1021 .
docker run --rm -p 10021:80 sologsb-1021
```

构建阶段生成静态站点，运行阶段由 nginx 监听容器 `80`。宿主端口 `10021` 仅由根端口表或部署命令映射。

## 数据说明

词典数据与版本历史保存在当前浏览器。离线工作不会调用后端；导出备份会生成包含词条、版本、审计记录的 JSON 文件（仅供恢复）。与同事交换数据请使用「同步副本」中心导出的**同步包**（`kind: sologsb-dictionary-sync`），同步包含墓碑，能正确合并撤下与并发编辑。
